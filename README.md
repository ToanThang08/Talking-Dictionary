# Говорящий словарь (Speaking Dictionary)

Проект "Говорящий словарь" — это десктопное приложение на C# WinForms, которое позволяет:

- Хранить пары слов (иностранное слово и его перевод);
- Озвучивать иностранное слово с помощью встроенной функции TTS (Text-to-Speech);
- Использовать удобный графический интерфейс для работы со словарем.

## 🎯 Возможности

- Поиск слова и его перевода
- Добавление новых слов
- Удаление и редактирование записей
- Озвучка слов (System.Speech)
- Хранение словаря в XML

## 🛠️ Технологии

- C#
- WinForms (.NET Framework)
- Visual Studio 2022
- System.Speech.Synthesis
- Git + GitHub
